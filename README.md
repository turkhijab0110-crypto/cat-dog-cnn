# 🐱🐶 Cat vs Dog Image Classification using CNN

A deep learning project that uses a **Convolutional Neural Network (CNN)** built with **PyTorch** to classify images into two categories: **Cat** or **Dog**.

---

## 📌 Introduction

The main purpose of this project is to develop a **computer vision model capable of classifying images into two categories: Cat or Dog**.

For this project, we created a **Convolutional Neural Network (CNN)** using **PyTorch**. The model is trained on cat and dog images so that it can learn important visual features and predict the class of a new image.

This is a **binary classification problem** because the model has only two possible output classes: **Cat** and **Dog**.

The project demonstrates the complete workflow of a basic deep learning application, including **data preparation, image preprocessing, CNN architecture, model training, evaluation, model saving, and image prediction**.

---

## 🎯 Project Objective

The objectives of this project are:

- Build a CNN-based image classification model.
- Train the model to distinguish between cats and dogs.
- Apply image preprocessing and data augmentation.
- Evaluate the trained model using test data.
- Save the trained model for future predictions.
- Create a prediction script that classifies a new image.

---
